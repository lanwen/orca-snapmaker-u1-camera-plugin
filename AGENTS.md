# Agent instructions

When creating a PR or updating its description, read and use the repository's [pr skill](.agents/skills/pr/SKILL.md).
The GitHub [PR template](.github/pull_request_template.md) is the single source for the description format.

For visual changes, recommend rebuilding the [all-states HTML preview](docs/development.md#readme-screenshots) for review.
Share `dist/screenshots/index.html` and check affected states at desktop and narrow widths.
